Security checklist

• This page does not ask for seed phrases, private keys, or passwords.

• The connected account must be the account you intend to spend from.

• A website connection alone does not grant permission to move funds; each transfer requires your wallet's confirmation.

• Never approve an unexpected signature, token approval, or transaction.

Static client-side page. No server stores your address or transaction details. Network calls and any transaction request go through the wallet provider and its configured RPC. Inspect the source before using real funds.
